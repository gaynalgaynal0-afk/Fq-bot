# Telegram AI Bot 🤖

AI-powered Telegram bot for channel @jv_60fps

## Features
- Direct AI replies
- Channel product support
- Issue solving
- Chat memory

## Setup

1. Add .env file
2. Install:
   npm install
3. Run:
   npm start

## Deploy on Render

- Create new Web Service
- Connect GitHub repo
- Add environment variables:
  TELEGRAM_TOKEN
  OPENAI_KEY
- Start command:
  npm start
